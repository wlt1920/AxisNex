2. WHAT THE SOFTWARE DOES TO YOUR SYSTEM
To work, the Software makes changes to your Windows system. By installing it you agree to these changes:
a) It installs the HIDMaestro user-mode driver, which creates a virtual controller. HIDMaestro installs a self-signed driver certificate named "HIDMaestroTestCert" into the "Trusted Root Certification Authorities" and "Trusted Publishers" stores of your computer so that its driver can load.
b) It installs HidHide (by Nefarius Software Solutions), a filter driver that hides your physical controller from games while the Software is running.
c) It installs the hidusbf driver by SweetLow (Microsoft-signed), which sets the USB polling interval of a wired controller to 1 ms (1000 Hz). This can be switched off in the app and is removed from the controller on uninstall.
d) It registers itself in HidHide's list of allowed applications, raises its own process priority while running, and stores its settings and profiles in your Windows user profile (AppData) and in the registry (current user and, for installation state, the local machine).
After the first installation, Windows must be restarted before the Software is used, so that the drivers can load.
Uninstalling AxisNex removes the application. HidHide, the HIDMaestro driver and its certificate stay installed and can be removed separately from Windows Settings / Device Manager / Certificate Manager (certlm.msc).
