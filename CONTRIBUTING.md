# Contributing to AxisNex

Thanks for helping improve AxisNex. This repository holds the public page, documentation, license texts and releases. The AxisNex source code is not public, so code pull requests aren't possible here — but there is still plenty that helps.

## Ways to help

- **Report bugs** with the [bug report template](https://github.com/wlt1920/AxisNex/issues/new?template=bug_report.yml). Include your AxisNex version, Windows version, controller and connection type, and the exact steps.
- **Suggest features** with the [feature request template](https://github.com/wlt1920/AxisNex/issues/new?template=feature_request.yml). Describe the problem first, then your idea.
- **Give feedback on Advanced tuning.** It isn't fully tested yet; tell us what worked, what felt off and which values you used.
- **Fix the docs.** Typos, unclear steps or outdated information in the README, [docs/](docs/) or the [changelog](CHANGELOG.md) can be fixed with a pull request.
- **Improve translations.** AxisNex is available in 11 languages. If a text in your language is wrong or sounds unnatural, open an issue with the current text, a screenshot and your suggested wording.
- **Ask and share** in [Discussions](https://github.com/wlt1920/AxisNex/discussions).

## Before opening an issue

- Check the [Troubleshooting](README.md#troubleshooting) section and existing issues.
- Make sure you're on the latest version ([Releases](https://github.com/wlt1920/AxisNex/releases/latest)).
- Never post passwords, account names, email addresses or other personal information.
- Report security problems privately, as described in [SECURITY.md](SECURITY.md).

## Pull requests (docs only)

- Keep changes focused; one topic per pull request.
- Describe features only as they actually work in the current release.
- Use third-party product and game names only to describe compatibility. Don't add third-party logos, artwork or screenshots of other projects.
- If you change the English README, mention it in the pull request so the [Romanian README](docs/README_RO.md) can be kept in sync.

By submitting a contribution you confirm that it is your own work and agree that wLt may use it in AxisNex and its documentation.
